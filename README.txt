JARVIS AI ASSISTANT — STARTER PACKAGE

1. Extract this ZIP on your phone or computer.
2. Open the folder and tap index.html.
3. Choose Chrome if your phone asks which app to use.

Included:
- Mobile-friendly JARVIS dashboard
- Live clock
- Chat interface (demo replies)
- Browser speech-to-text button where supported

IMPORTANT:
This is a front-end starter project. It is not connected to a real AI model yet.
To add real AI answers, connect a secure backend/API. Never put a private API key
inside index.html or publish it in a public repository.
